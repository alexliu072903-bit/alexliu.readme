## 问题

AirJelly 是运行在桌面上、感知上下文的主动式 Agent。用户的信息散落在聊天、文档、任务和不同的会话里，Codex、Claude Code 这类外部 Agent 看不到，每次都要人重新交代背景。

## 我负责的方向：为 Agent 整合 Context

我提出的方向是把散落在不同应用、任务和会话里的用户 Context 整合起来，交给外部 Agent，让模型带着完整信息继续工作。落到产品和底层链路上，涉及 Context 的组装、相关性排序、范围与 Token Budget、访问控制、多实例选择，以及用户能看到哪些内容交给了 Agent。

## 2.0 的产品结构

我负责搭建 2.0 以 Agent Context 为核心的产品体系，参与功能规划与优先级，让产品结构在 2.0 发布前收敛下来。
